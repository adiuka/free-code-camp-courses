# build-a-boiler-plate

Learned to use the CLI to create a website boiler-plate

I made this boilerplate
from the command line
for the freeCodeCamp bash lessons

## commands:

1. echo hello terminal
2. pwd
3. ls
4. cd freeCodeCamp/
5. pwd
6. cd.. 
7. more package.json
8. clear
9. cd node_modules/
10. ls -l
11. cd ../..
12. mkdir website
13. cd website
14. touch index.html
15. touch styles.css
16. touch index.js
17. touch .gitignore
18. ls -a
19. touch background.jpg
20. touch header.png
21. touch footer.jpeg
22. mkdir images
23. cp background.jpg images
24. rm background.jpg
25. mv roboto.font roboto.woff
26. mkdir fonts
27. mv roboto.woff fonts
28. find
29. mkdir client
30. mkdir client/src
31. mv index.html client/src
32. find client
33. find -name index.html
34. find -name src
35. mv ./images/footer.jpeg client/assets/images
36. rmdir images
37. touch package.json
38. echo I made this boilerplate >> README.md
39. cp -r website-boilerplate toms-website
